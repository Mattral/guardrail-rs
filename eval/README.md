# Detection evaluation

How often guardrail-rs flags prompt injection, measured on labelled data
rather than on examples written alongside the rules.

- **Results:** [RESULTS.md](RESULTS.md) for the pattern rules (regenerated by
  the test below), and [docs/benchmarks.md](../docs/benchmarks.md#detection)
  for the optional ML model.
- **Not measured yet:** PII redaction, toxicity, and policy rules.

## What runs in CI

`crates/guardrail-test-suite/tests/detection_eval.rs` sends every case
through the default pipeline and records which ones are blocked as
`prompt_injection`. It fails when the result differs from
[baseline.json](baseline.json): a missed injection or a new false alarm is a
regression, and an improvement has to be recorded so the published numbers
stay current.

```bash
cargo test -p guardrail-test-suite --test detection_eval -- --nocapture
```

After an intended change to the rules, record the new results and commit
both files:

```bash
GUARDRAIL_EVAL_UPDATE=1 cargo test -p guardrail-test-suite --test detection_eval
git add eval/baseline.json eval/RESULTS.md
```

## Datasets

| File | Source | Cases | In git |
|---|---|---|---|
| `data/deepset-prompt-injections.jsonl` | [deepset/prompt-injections](https://huggingface.co/datasets/deepset/prompt-injections) at `4f61ecb0`, train and test splits | 263 injections, 399 benign | yes |
| `tests/fixtures/*.json` | this repository | 7 injections, 6 benign | yes |
| `data/external/jackhhao-jailbreak-classification.jsonl` | [jackhhao/jailbreak-classification](https://huggingface.co/datasets/jackhhao/jailbreak-classification) at `2f2ceeb3` | 666 jailbreaks, 1,332 benign | no: `python3 eval/fetch-jackhhao.py` |

Both external datasets are Apache-2.0; the copies here are converted to one
JSON object per line (`id`, `label`, `text`) without changing the text or
the labels.

Read the numbers with these in mind:

- **Labels are the datasets' own.** Some deepset "injections" are ordinary
  requests (for example "Generate SQL code to access a database"), and part
  of deepset is in German. A low catch rate there still means the rules miss
  most of what the dataset's authors count as injection.
- **The hand-written fixtures are not a test of quality.** They were written
  with the rules, so they show intended behaviour only.
- **The ML model was trained on jackhhao's data**, according to its
  [model card](https://huggingface.co/protectai/deberta-v3-base-prompt-injection-v2),
  so its jackhhao score is not an independent result. deepset is not listed
  among its training sets.
- **These are two public datasets, not your traffic.** Rates on real
  requests can be higher or lower.

## Adding data

New labelled cases are the most useful contribution to this directory:
real injection attempts the rules miss, and harmless text they flag. Add
them as JSONL in `data/` with a source and licence that allow
redistribution, list the file here, add it to `datasets()` in the test, and
record a new baseline.
